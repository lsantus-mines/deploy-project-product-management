# KB-214 · Exporting payroll runs

## Export a run as CSV
Open **Payroll → Runs**, select the month and scroll to the bottom of the page: the **Export** link is under the totals. Choose **CSV – accountant format**. The file includes gross, net, employer contributions and the run status.

## Payslips as PDF
From the same run, **Export → Payslips (PDF, zip)**. One file per employee.

## Scheduled exports
**Settings → Integrations → Scheduled export** sends the CSV to an e-mail address or an SFTP folder on the day the run is validated.
