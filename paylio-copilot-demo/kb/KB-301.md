# KB-301 · Users, roles and SSO

## Add an admin user
**Settings → Users → Invite**. Choose the role *Admin*. The invitation link is valid for 7 days.

## Read-only access for an accountant
Invite with the role *Viewer (finance)*: payroll and invoices are visible, nothing can be edited.

## Single sign-on
**Settings → Security → SSO**. Google Workspace and Microsoft Entra are supported. If the login loops back to the login page, check that the user's e-mail in the directory matches the one in the app.
