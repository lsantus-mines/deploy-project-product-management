# KB-214 · Exporting payroll runs

## Export a run as CSV
Open **Payroll → Runs**, select the month and click **Export** (top right, since release 4.12). Choose **CSV – accountant format**. The file includes gross, net, employer contributions and the run status.

## Payslips as PDF
From the same run, **Export → Documents → Payslips (PDF, zip)**. One file per employee.

## Scheduled exports
**Settings → Integrations → Scheduled export** sends the CSV to an e-mail address or an SFTP folder on the day the run is validated. After release 4.12, re-enable the schedule once: it is paused by the update.

## Release notes 4.12
What changed in the latest release, version 4.12: the Export button moved from the bottom of the Runs page to the top right; the export opens on a new page; the CSV column order changed (new accountant format) — choose **Legacy CSV** in the Export menu to get the previous format and column order back; "Payslips" is now under **Export → Documents**; scheduled exports are paused after the update and must be re-enabled. Full release notes: Help → What's new.
