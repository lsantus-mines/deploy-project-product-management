# KB-318 · Employees: import, leavers, pay date

## Bulk import from Excel
**Employees → Import**. Download the template first; the columns must keep their names. Errors are listed per line after the upload.

## Archiving a leaver
Open the employee → **Actions → Archive**. The last payslip must be issued first.

## Changing the company pay date
**Settings → Payroll → Pay date**. The change applies from the next run; the current run is not affected.
